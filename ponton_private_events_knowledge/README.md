# El Ponton - Knowledge Eventos Privados

Este addon instala la base inicial de Conocimientos para operar eventos
privados de El Ponton.

Las paginas se cargan como `document.page` con `noupdate="1"` para que el
equipo pueda ajustar redaccion, responsables o detalles diarios desde Odoo sin
que una actualizacion del modulo pise esos cambios.

Cuando cambie una regla permanente del proceso, por ejemplo una validacion de
reserva, una politica comercial, un flujo de cierre Fudo o una responsabilidad
formal entre areas, el cambio debe volver al addon como nueva version de datos
o como migracion.

No incluir en estas paginas credenciales, datos de clientes reales, links
privados de Fudo, comprobantes ni informacion sensible. La documentacion debe
explicar el proceso, no almacenar evidencia operativa.
